# MedRoute – Emergency Ambulance Dispatch Language Compiler

**MedRoute is a domain-specific programming language and compiler that translates emergency ambulance dispatch instructions into validated intermediate operations and simulates their execution.**

This project is a complete, production-quality Compiler Design Mini Project that implements a full compiler for the MedRoute language. It includes lexical analysis, syntax analysis, semantic analysis, intermediate code generation, and an execution engine, accompanied by a professional visual IDE.

## 🌟 Core Project Concept

MedRoute replaces manual UI interactions (like clicking "Register Patient" or "Dispatch Ambulance") with a custom Domain-Specific Language (DSL). The user writes a MedRoute program, which the compiler parses, validates, and executes to simulate emergency dispatch scenarios.

### Example MedRoute Program
```medroute
// Emergency ambulance scenario
PATIENT P101
LOCATION P101 "Sardar Patel Road"
SEVERITY P101 CRITICAL

AMBULANCE A12
HOSPITAL H01 "City Hospital"

DISPATCH A12 P101
ROUTE A12 H01
PRIORITY A12 HIGH

STATUS A12
ARRIVE A12
TRANSFER P101 H01
REPORT
```

### The Compilation Pipeline
The MedRoute compiler processes the program through standard compiler phases:
1. **Source Code**
2. **Lexical Analysis (Flex)** -> Generates Tokens
3. **Syntax Analysis (Bison/YACC)** -> Generates Parse Tree
4. **Semantic Analysis** -> Validates logical rules & populates Symbol Table
5. **Intermediate Code Generation** -> Creates execution-ready IR
6. **Execution Engine** -> Executes IR and updates the simulation state

## 🏗️ Architecture

The project is built with a clear separation of concerns, divided into two main layers:

1. **Compiler Core (C/C++, Flex, Bison)**: The academic heart of the project. It handles tokenization, parsing, semantic validation, symbol table management, IR generation, and execution.
2. **Visual Interface (React, TypeScript, Tailwind CSS)**: A professional compiler IDE that provides a code editor (Monaco), visualizes the compilation pipeline, and displays a live map simulation.

## 🚀 Features

*   **Custom Language**: A complete DSL with custom keywords (`PATIENT`, `LOCATION`, `SEVERITY`, `AMBULANCE`, `HOSPITAL`, `DISPATCH`, `ROUTE`, `PRIORITY`, `STATUS`, `ARRIVE`, `TRANSFER`, `CANCEL`, `REPORT`).
*   **Real Lexer & Parser**: Built using industry-standard tools (Flex and Bison).
*   **Strict Semantic Validation**: Prevents logically invalid operations (e.g., dispatching an ambulance that doesn't exist, arriving before dispatching).
*   **Symbol Table Management**: Tracks the state and attributes of Patients, Ambulances, and Hospitals.
*   **Intermediate Code**: Dynamically generates execution instructions from valid ASTs.
*   **Execution Engine**: Simulates the state transitions of ambulances and patients based on IR.
*   **Professional IDE**: An integrated frontend to write code, view compiler phases (Tokens, Syntax, Semantics, Symbol Table, IR), and visualize the emergency map.

## 🚫 Anti-Patterns (What this project is NOT)

*   This is **not** a standard CRUD web application.
*   This is **not** using JavaScript regex for parsing. The parser is genuinely built with Flex/Bison.
*   This is **not** faking compiler output. The tokens, parse trees, and symbol tables shown in the UI are genuinely generated by the C/C++ compiler.

## 🎓 Academic Context
This project is designed for a Compiler Design college mini-project. It thoroughly demonstrates all standard phases of a compiler using a highly practical and engaging domain (emergency dispatch) rather than a generic calculator or toy C-subset compiler.
